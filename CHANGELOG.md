# Changelog

## [1.3.0] — 2026-10-11

### Исправления и улучшения

- **Фоновое обновление статуса компонентов:** устранена гонка при регистрации PID фонового процесса. Воркер публикует свой PID перед выполнением обновления; удаление блокировки привязано к PID родительского процесса.
- **Запуск из нестандартного пути:** фоновое обновление использует текущий доступный файл скрипта, а не безусловно жёстко заданный `/opt/bin/xmenu`.
- **Очистка при завершении:** Xmenu завершает принадлежащий текущему сеансу воркер обновления компонентов и очищает его блокировку. Исправлены PID-зависимые пути временных файлов.
- **Загрузка через wget:** если системная команда `timeout` или апплет `busybox timeout` отсутствуют, Xmenu больше не блокирует вызов wget только из-за этого. Сохраняются сетевой тайм-аут `-T` и одна попытка `-t 1`.
- **Защита резервных копий:** удаление Xmenu сначала предлагает сохранить архивы конфигураций. Сохранение выбрано по умолчанию; удаление архивов требует отдельного явного подтверждения.
- **Быстрее отрисовка меню:** короткие пункты меню печатаются без запуска внешнего `awk`; перенос строк сохраняется для длинных пунктов.
- **Нет лишней переустановки:** при запуске копии скрипта Xmenu сравнивает её с `/opt/bin/xmenu` и не перезаписывает идентичный файл.
- **Версия обновлена до 1.3.0.**

### Совместимость и проверка

- Ориентировано на Keenetic / Netcraze с Entware и BusyBox `ash`.
- Проверка синтаксиса выполняется через `sh -n xmenu-v1.0.sh` в GitHub Actions.
- Проверка синтаксиса не заменяет испытания на физическом роутере; реальные сетевые тайм-ауты и поведение процессов зависят от прошивки и набора апплетов BusyBox.
