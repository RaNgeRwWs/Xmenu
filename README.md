## ⚡ Быстрый старт

Подключись к роутеру по SSH под `root`. Перед установкой убедись, что Entware установлен в `/opt` и роутер имеет доступ к выбранному источнику загрузки. Выбери один из трёх способов ниже. Скрипт скачивается во временный файл, проверяется командой `sh -n`, а прежний `/opt/bin/xmenu` при наличии сохраняется с отметкой времени.

### 1. GitHub Raw через `curl`

```sh
mkdir -p /opt/bin && curl -fL --retry 3 'https://raw.githubusercontent.com/rangerxxyy/Xmenu/main/xmenu-v1.0.sh' -o /tmp/xmenu.sh && sh -n /tmp/xmenu.sh && { [ ! -f /opt/bin/xmenu ] || cp -p /opt/bin/xmenu "/opt/bin/xmenu.bak.$(date +%Y%m%d-%H%M%S)"; } && cp /tmp/xmenu.sh /opt/bin/xmenu && chmod 700 /opt/bin/xmenu && /opt/bin/xmenu
```

### 2. GitHub Raw через `wget`

```sh
mkdir -p /opt/bin && wget -O /tmp/xmenu.sh 'https://raw.githubusercontent.com/rangerxxyy/Xmenu/main/xmenu-v1.0.sh' && sh -n /tmp/xmenu.sh && { [ ! -f /opt/bin/xmenu ] || cp -p /opt/bin/xmenu "/opt/bin/xmenu.bak.$(date +%Y%m%d-%H%M%S)"; } && cp /tmp/xmenu.sh /opt/bin/xmenu && chmod 700 /opt/bin/xmenu && /opt/bin/xmenu
```

### 3. jsDelivr — зеркало GitHub

```sh
mkdir -p /opt/bin && curl -fL --retry 3 'https://cdn.jsdelivr.net/gh/rangerxxyy/Xmenu@main/xmenu-v1.0.sh' -o /tmp/xmenu.sh && sh -n /tmp/xmenu.sh && { [ ! -f /opt/bin/xmenu ] || cp -p /opt/bin/xmenu "/opt/bin/xmenu.bak.$(date +%Y%m%d-%H%M%S)"; } && cp /tmp/xmenu.sh /opt/bin/xmenu && chmod 700 /opt/bin/xmenu && /opt/bin/xmenu
```

Для способов 1 и 3 нужен `curl`, для способа 2 — `wget`. Если утилиты отсутствуют, установи их из Entware одной командой: `opkg update && opkg install curl wget`.

При успешном запуске меню показывает модель устройства, версию KeeneticOS, архитектуру и обнаруженные компоненты. Для следующего запуска используй:

```sh
xmenu
```

Обновить установленный Xmenu можно пунктом **22 — «Обновить Xmenu»**. Команда `xmenu update-xmenu` запускает ту же операцию из SSH. Проверка наличия новой версии через `U` только сообщает о доступном обновлении и не заменяет файлы автоматически.

## Что такое Xmenu

Xmenu — один POSIX shell-скрипт, который собирает установку и базовое обслуживание совместимых компонентов в одном меню. Он работает поверх Entware и вызывает штатные пакетные менеджеры, установщики и службы соответствующих проектов. Сам Xmenu не является прокси-сервером и не заменяет конфигурацию выбранных компонентов.

Меню рассчитано на пользователей, которые подключаются к роутеру через SSH и понимают, какие компоненты им нужны. Установка и удаление меняют системные файлы и пакеты. Перед такими операциями прочитай описание пункта на экране и сохрани важные конфигурации.

## Требования и совместимость

- Роутер Keenetic или Netcraze с доступом к командной строке по SSH.
- Права `root` для установки пакетов, настройки служб и записи в системные каталоги.
- Установленный Entware в `/opt`; команда `opkg` должна запускаться.
- Интернет-доступ к GitHub, зеркалам загрузки и репозиториям пакетов для сетевых действий.
- Свободное место в `/opt` для пакетов, временных файлов, кэша и резервных копий.
- Совместимая архитектура Entware и прошивка для выбранного компонента.

Некоторые сетевые компоненты зависят от поддержки Netfilter и модулей ядра в конкретной прошивке. Требования отличаются между NFQWS, NFQWS2 и другими пакетами. Xmenu не устанавливает Entware или недостающие модули ядра автоматически; перед установкой проверь требования проекта компонента.

Команды загрузки рассчитаны на наличие `curl` или `wget`. Для проверки стратегий, зеркал OPKG и обновлений также нужен работающий DNS и доступ наружу. Если роутер использует фильтрацию или прокси, доступность каждого источника может отличаться.

## Как пользоваться меню

Главный экран разделён на группы. Номера операций постоянны, поэтому их можно использовать в инструкциях и сообщениях об ошибках. Между основными группами добавлены интервалы, чтобы меню было легче просматривать на небольшом терминале.

```text
[::]  Установка / обновление:
  1–6   Отдельные компоненты

[::]  Ручные настройки установки:
  7–10  Профили с Mihomo или Xray

[::]  Стратегии / blobs / lists:
  11–14 Стратегии и списки

[::]  Утилиты и диагностика:
  15–18 DPI Detector, TG WS Proxy Rust, KeenKit, awg-manager

[::]  Обслуживание и настройки:
  19    Язык интерфейса
  20    Удаление компонентов
  21    Удалить Xmenu
  22    Обновить Xmenu
  23    Настройки OPKG / зеркала Entware
  0     Выход
```

Пункт `U` в строке приглашения вручную проверяет обновление Xmenu. Когда появляется новая версия, подсказка отображается под пунктом `U`; установка запускается отдельно пунктом **22**. Статус установленных компонентов обновляется в фоне, поэтому сетевые запросы не должны задерживать открытие главного экрана.

Можно открыть Xmenu одновременно в нескольких SSH-сессиях. Для операций, которые записывают общие настройки, скрипт использует кратковременную защиту записи. Эта защита не запрещает запуск меню с другого устройства.

### Установка и профили

Пункты **1–6** устанавливают или обновляют отдельные компоненты: XKeen Stable, панели XKeen UI, NFQWS2, веб-компонент NFQWS и пользовательский интерфейс NFQWS2.

Пункты **7–10** предлагают комплексные профили на базе Mihomo или Xray. Перед установкой профиль проверяет необходимые зависимости и последовательно настраивает компоненты. Состав включает XKeen Auto, GeoIPSet, ядро Xray или Mihomo и указанные в меню дополнительные панели и NFQWS-пакеты. Если один шаг завершается ошибкой, проверь сообщение этого шага и состояние установленных пакетов перед повторным запуском.

Для загрузки используются официальные страницы релизов и установщики проектов. Перед применением загруженные файлы проверяются доступными для конкретного компонента средствами; подробности и ограничения описаны в выводе установщика.

### Стратегии и списки NFQWS

Пункт **11** показывает подходящие стратегии для установленного NFQWS или NFQWS2. Скрипт сверяет активную стратегию с текущей конфигурацией, чтобы не помечать устаревший файл-маркер как действующий. Имя текущего варианта выделяется бирюзовым цветом.

После выбора стратегия загружается либо берётся из локального кэша. Перед применением Xmenu проверяет контрольную сумму и сохраняет прежнюю конфигурацию. Если проверка загрузки или контрольной суммы не проходит, кандидат не применяется. После замены конфигурации перезапускается соответствующая служба; если перезапуск не удался, сообщение об этом выводится отдельно.

Смежные пункты:

- **12** загружает или проверяет blobs и списки, указанные активной стратегией.
- **13** устанавливает доступные blobs для NFQWS2.
- **14** загружает список `rkn.list` и добавляет нужную ссылку в конфигурацию, если выбранный пакет её поддерживает.

NFQWS v1 и NFQWS2 используют разные файлы конфигурации и каталоги ресурсов. Основные конфиги находятся в `/opt/etc/nfqws/nfqws.conf` и `/opt/etc/nfqws2/nfqws2.conf`. Не копируй blobs между версиями без проверки формата и назначения.

### OPKG и зеркала Entware

Открой пункт **23 — «Настройки OPKG / зеркала Entware»**. Текущий источник пакетов показывается в заголовке. Бирюзовый заголовок и цветовая отметка активного адреса помогают отличить текущий выбор от остальных.

1. **Авто-выбор доступного репозитория Entware** — проверяет зеркала и выбирает доступное с лучшим временем ответа.
2. **Проверить доступность зеркал Entware** — показывает состояние, регион и адрес каждого источника.
3. **Выбрать зеркало Entware вручную** — показывает доступные варианты и отмечает текущий; при входе в список проверка сети не запускается.
4. **Восстановить копию `opkg.conf`** — возвращает последнюю сохранённую Xmenu копию конфигурации.
5. **Выполнить `opkg update`** — обновляет локальные индексы пакетов.

Проверка доступности анализирует файл `Packages.gz` и его содержимое. Успешный ответ сервера сам по себе не считается достаточным: страница блокировки, HTML вместо индекса или повреждённый архив означают, что источник не подходит. При сетевой ошибке выполняется ограниченная повторная попытка.

Перед переключением источника Xmenu сохраняет конфигурацию. Основной файл находится в `/opt/etc/opkg.conf`, резервные копии OPKG — в `/opt/etc/xmenu/backups/`. После смены зеркала источник применяется сразу; запусти пункт **5**, чтобы обновить списки доступных пакетов. `opkg update` загружает индексы, но не устанавливает и не обновляет сами пакеты.

### Удаление и резервные копии

Пункт **20** открывает подменю удаления. Основные действия пронумерованы постоянно:

```text
1.  XKeen — полная деинсталляция
2.  XKeen UI — zxc-rv
3.  DPI Detector
4.  nfqws2-keenetic
5.  nfqws-keenetic-web
6.  Mihomo
7.  Удалить все пакеты NFQWS
8.  Удалить резервные копии (*.bak, *.bak.* / *-opkg)
9.  Удалить все blobs NFQWS2 (*.bin)
10. Удалить все бэкапы Xmenu
11. Другие установленные компоненты
0.  Назад
```

Перед удалением компонентов запрашивается подтверждение. Xmenu старается сохранить конфигурации, если штатный деинсталлятор компонента это позволяет. Отдельные действия удаляют именно выбранные данные:

- **Пункт 8** перечисляет найденные файлы резервных копий в каталогах конфигураций и удаляет только совпадения с масками `*.bak`, `*.bak.*` и `*-opkg`. Если сканирование каталога завершилось ошибкой, удаление отменяется.
- **Пункт 9** удаляет файлы `*.bin` из каталога blobs NFQWS2.
- **Пункт 10** очищает резервные копии Xmenu и сохранённые архивы конфигураций, сам установленный `/opt/bin/xmenu` не удаляет.
- **Пункт 11** показывает прочие обнаруженные компоненты, например дополнительные панели или утилиты, для которых нет места в основном списке.

Для ручного создания архива конфигураций выполни `xmenu backup`. Архив сохраняется в каталоге резервных копий Xmenu. Команда доступна, хотя отдельного пункта создания архива в главном меню нет.

Пункт **21 — «Удалить Xmenu»** удаляет сам скрипт. Перед подтверждением можно сохранить резервные копии; внимательно прочитай запрос, чтобы выбрать нужный вариант.

## Команды запуска

Xmenu можно запускать из любого каталога, если `/opt/bin` присутствует в `PATH`. Основные интерактивные действия также доступны как аргументы:

```sh
xmenu                    # открыть главное меню
xmenu status             # показать устройство и установленные компоненты
xmenu update-xmenu       # обновить Xmenu
xmenu strategies         # открыть меню стратегий
xmenu sync               # синхронизировать ресурсы активной стратегии
xmenu opkg-settings      # открыть настройки OPKG и Entware
xmenu backup             # создать архив конфигураций
```

Операции, которые открывают меню или требуют подтверждения, рассчитаны на интерактивный SSH-терминал. Для обхода `PATH` используй `/opt/bin/xmenu`. Если команда не находится после установки, открой новый SSH-сеанс или запусти её по полному пути.

## Где хранятся файлы

Основные пути на роутере:

- `/opt/bin/xmenu` — установленный скрипт.
- `/opt/etc/xmenu/` — внутренний кэш, настройки языка и служебные данные.
- `/opt/etc/xmenu/backups/` — копии конфигураций и архивы, созданные Xmenu.
- `/opt/etc/xmenu/language` — язык интерфейса (`ru` или `en`).
- `/opt/etc/opkg.conf` — источники Entware для пакетного менеджера.
- `/opt/etc/nfqws/nfqws.conf` — конфигурация NFQWS v1, если пакет установлен.
- `/opt/etc/nfqws2/nfqws2.conf` — конфигурация NFQWS2, если пакет установлен.

В репозитории находятся:

- `xmenu-v1.0.sh` — основной скрипт на POSIX `sh`, совместимый с BusyBox `ash`.
- `README.md` — эта инструкция.
- `CHANGELOG.md` — подробная история изменений.
- `tests/` — регрессионные сценарии и проверка ввода меню.
- `.github/workflows/` — автоматические проверки скрипта при изменениях.

## Если что-то не работает

### Не скачивается скрипт

Проверь DNS и HTTPS-доступ с роутера, затем попробуй другой способ из раздела «Быстрый старт». Для `curl` ошибка HTTP-кода видна благодаря параметру `-f`. Для первичной диагностики можно выполнить `which curl`, `which wget` и `date`.

### Не удаётся установить пакет

Проверь вывод `opkg update`, архитектуру `opkg print-architecture` и свободное место командой `df -h /opt`. Убедись, что источник пакета подходит для архитектуры Entware и прошивки. Сообщение установщика конкретного проекта часто содержит причину несовместимости.

### Зеркала отображаются недоступными

Проверка требует получить и разобрать `Packages.gz`, а не просто ответить на ping. Проверь дату и время роутера, DNS, HTTPS-соединение и возможность загрузить индекс с роутера. Если проверка не проходит, ручной список позволяет увидеть адреса и текущий источник; не переключайся на источник, который не подходит твоей архитектуре.

### Меню закрывается или ввод не принимается

Используй обычную интерактивную SSH-сессию и вводи номер пункта без дополнительных символов. Включи эмуляцию UTF-8 в SSH-клиенте, если рамки и кириллица отображаются неправильно. Xmenu допускает несколько одновременных SSH-сессий; если зависла только одна операция, сначала проверь, не выполняется ли установка или обновление.

При обращении приложи модель роутера, версию KeeneticOS, архитектуру, выбранный пункт и полный текст ошибки. Удали из вывода пароли, токены и приватные ключи.

## Проверки проекта

GitHub Actions проверяет синтаксис POSIX shell, запускает ShellCheck, выполняет регрессионные сценарии в BusyBox `ash` и проверяет интерактивный ввод через PTY. Чтобы повторить проверки локально на Linux:

```sh
sh -n xmenu-v1.0.sh
shellcheck -s sh -S warning xmenu-v1.0.sh
busybox ash tests/regression.sh
python3 tests/menu_input.py
```

Регрессионные сценарии используют временные файлы и тестовые ответы; они не настраивают реальный роутер и не доказывают доступность зеркал из конкретной сети.

## Отказ от ответственности

Xmenu предоставляется «как есть». Использование скрипта, установка и удаление компонентов, изменение конфигураций и любые последствия этих действий выполняются пользователем на свой страх и риск.
